# Odin Recipes

Petit site de recettes de cuisine construit en HTML pur (sans CSS pour le moment), réalisé dans le cadre du curriculum The Odin Project.

## Compétences démontrées
- Structure HTML de base (boilerplate)
- Navigation entre plusieurs pages via des liens relatifs
- Utilisation de listes ordonnées et non ordonnées
- Organisation de fichiers/dossiers dans un projet web
